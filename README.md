# CuraDesk

لوحة تحكم متكاملة لإدارة العيادات — المرضى، المواعيد، السجلات الطبية، الوصفات، الفواتير والإشعارات، بواجهة عربية بالكامل (RTL).

## المزايا

- **إدارة المرضى**: بحث فوري، عرض جدول أو بطاقات، وحذف بمهلة تراجع (undo).
- **المواعيد**: تجميع حسب التاريخ، حالة الموعد (مجدول/مكتمل/ملغى/لم يحضر).
- **السجلات الطبية والوصفات**: صلاحيات مبنية على الدور (الطبيب فقط يضيف/يعدّل).
- **الفواتير**: تتبع المدفوع والمتبقي بعملة العيادة.
- **لوحة تحكم حيّة**: إحصائيات فورية، مواعيد اليوم، ورسم بياني لآخر 7 أيام.
- **تخصيص فعلي**: لون الواجهة يتغيّر حسب تخصص العيادة، ووضع داكن حقيقي — الاثنان من إعدادات العيادة مباشرة.
- **تصميم متجاوب**: قائمة جانبية قابلة للطي على الموبايل والتابلت.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | React 19 + Vite |
| التوجيه | React Router 7 |
| الأنماط | SCSS + CSS Custom Properties (ثيم ديناميكي) |
| الطلبات | Axios |
| الأيقونات | Lucide React |
| الخلفية | Strapi (منفصل، غير موجود بهذا المستودع) |

## التشغيل محلياً

```bash
npm install
cp .env.example .env   # وحطي رابط الـ Strapi API تبعك
npm run dev
```

المشروع بيحتاج سيرفر Strapi شغال (راجعي `.env.example` لأسماء المتغيرات المطلوبة).

## البنية

```
src/
├── api/            # عميل Axios + معالجة الأخطاء والـ 401
├── components/     # مكوّنات قابلة لإعادة الاستخدام (فورمات، Modal، Toast...)
├── context/         # Auth / Toast / ClinicSettings
├── hooks/          # useAuth / useToast / useClinicSettings
├── pages/          # صفحات التطبيق (كل صفحة بمجلدها الخاص)
├── styles/         # نظام التصميم المشترك (متغيّرات، ثيم، أزرار، فورمات)
└── constants/       # قوائم ثابتة (التخصصات الطبية)
```
